Sobre el proyecto:

Combinamos una interfaz sencilla e intuitiva con una estética minimalista buscando que la experiencia sea fácil de entender y divertida.

Tecnologías usadas:

  • HTML5: estructura y contenido de las páginas.
  • CSS3: estilos y presentación visual.
  • JavaScript: lógica de los juegos, interacción con el usuario, validaciones y manejo de puntajes.
  • JSON: formato utilizado para interpretar las preguntas de la API y guardar los rankings.
  • GitHub: alojamiento y gestión del código del proyecto.
  • VSCode y Sublime Text: editores utilizados durante el desarrollo.
  • Open Trivia DB: fuente externa de preguntas para la trivia.

Créditos y fuentes externas

Para el desarrollo del juego de trivia utilizamos la API de Open Trivia Database, que proporciona preguntas y respuestas en formato JSON. En nuestro proyecto consultamos la categoría Entertainment: Music.

(Los recursos externos, como imágenes, íconos y tipografías, deben acreditarse según sus fuentes y licencias correspondientes.) Agradecemos a los creadores y colaboradores de las herramientas y recursos utilizados para hacer posible este proyecto.

Declaración de uso de inteligencia artificial

Durante el desarrollo de este proyecto utilizamos herramientas de inteligencia artificial, como GitHub Copilot y Claude, como apoyo para el aprendizaje y la resolución de problemas. Las utilizamos para consultar posibles soluciones, elaborar pseudocódigo, mejorar la organización y modularidad del JavaScript, comprender métodos y funciones, revisar el manejo de errores y explorar alternativas para implementar el almacenamiento de puntajes mediante LocalStorage. También las empleamos como apoyo para resolver dudas sobre la documentación de la API utilizada en la trivia. Las sugerencias generadas por estas herramientas fueron utilizadas como material de consulta y asistencia durante el proceso de desarrollo. El equipo se encargó de revisar, adaptar y probar las soluciones incorporadas al proyecto.
